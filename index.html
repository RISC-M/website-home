Inference-M

Our flagship project, an LLM Inference Accelerator.

OVERVIEW

Starting with a Network on a Chip

Inference-M is a custom manycore ML accelerator built around a novel paradigm called Direct Compute Access (DCA), in which the on-chip network borrows adjacent cluster ALUs to perform arithmetic reductions on data in-flight.

This eliminates the communication bottleneck that limits GEMM kernel utilization at scale.

The project involves writing behavioral simulators through RTL design, giving members end-to-end exposure across computer architecture, NoC design, RISC-V microarchitecture, and ML workload characterization.

Roadmap & Milestones

1
SUMMER 2026

Sim & Architecture

Test and simulate different hardware architectures, evaluate design trade-offs, and finalize the core microarchitecture.

2
FALL 2026

RTL Implementation

Write the SystemVerilog RTL and unit test individual compute, NoC, and memory blocks.

3
WINTER 2026

Integration & Verification

Make the hardware work seamlessly with PyTorch, run end-to-end verification, and validate execution on an FPGA.

4
SPRING 2027

Tapeout & Testing

Manufacture the physical silicon chip through ASIC tapeout and benchmark real neural network inference on fabricated hardware.
